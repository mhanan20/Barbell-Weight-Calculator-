Barbell Weight Calculator 

This project is a gym weight calculator designed to help users determine the most efficient way to load plates onto a barbell to reach a desired working weight, 
based on the available plates and barbell weight. It also includes a warmup calculator that generates appropriate warmup sets using the entered work weight and barbell weight, 
helping users prepare safely before exercising. The goal of this tool is to simplify weight setup at the gym while encouraging proper warmup habits.
